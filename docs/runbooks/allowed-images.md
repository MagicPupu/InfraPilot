# Allowed images

## Allowlist
Only these official images may be used: `nginx`, `redis`, `postgres`, `alpine`, `busybox` and `python`. Any tag is accepted.

## Third-party images
Images from other registries or user namespaces, such as `someorg/tool`, are refused.

## Requesting a new image
Open a request with the platform team. New images are reviewed for provenance and size before being added.
